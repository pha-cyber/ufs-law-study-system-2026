## Core workflow

1. Put lecturer material in the relevant module folder.
2. Audit course material before building or changing the study plan.
3. Keep verified dates, scope and weightings in `02-assessments/ASSESSMENT_MAP.md`.
4. Track mastery and review dates in `03-progress/PROGRESS_DASHBOARD.md`.
5. Record meaningful mistakes in `04-error-log/ERROR_LOG.md`.
6. Use `00-system/MASTER_STUDY_SYSTEM.md` as the tutor protocol.
7. Treat course material as the primary source for what is actually assessed.
8. Mark unverified information as **UNKNOWN** rather than inventing it.

## Mastery scale

Not studied → Introduced → Weak → Developing → Competent → Strong → Exam-ready

## Study principle

Studying should be conversational and active:

**diagnose → explain → retrieve → apply → correct → schedule review**

Recognition is not mastery. A topic becomes exam-ready only after accurate recall and application under appropriate exam conditions.
